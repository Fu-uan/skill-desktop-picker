# Skill 合集批量安装

## 目标与边界
用户已同意将 GitHub 导入改为支持整套安装和按需选择。合集是仓库中的多个独立 Skill；不生成合并的 SKILL.md，不改写原始技能，不执行仓库脚本。安装文件通过检查不代表 Agent 已运行验证。

## 交互
- 将链接导入与本地文件夹导入明确分开；本地导入保持单技能能力。
- GitHub 读取后显示仓库名、技能总数及“技能合集”说明；单项仍自动选择。
- 合集默认全选，支持全选、取消全选和逐项勾选。候选以技能名称为主，目录为辅助，展示可用中文说明，缺少中文说明时保留原描述，不能伪造翻译。
- 安装按钮显示所选数量及目标 Agent。零选中时禁用。
- 保留目标默认目录和高级自定义目录。
- 安装期间显示当前技能及已处理数量，禁止变更来源、选择和目标。
- 结果逐项区分“新安装并校验”“本地已存在且可扫描”“失败及原因”，同时显示总数。部分失败不能显示整套成功。返回列表清空旧搜索条件以展示已安装技能。

## 实现约束
- 下载一次、固定同一提交快照；检查和安装所有选择项共享该快照，整批完成后才释放。
- 主进程校验令牌、选择路径、去重及目标。渲染进程不能指定任意写入路径。
- 每个技能仍安装到目标目录下独立的技能名称目录，保留原有文件校验、路径安全和大小限制。
- 批次预检查选中项名称，阻止同批名称冲突（含 Windows 大小写冲突）；不静默覆盖或替换现有目录。
- 已存在目录通过元数据和扫描检查后重新索引，但不声称与远端内容完全一致。
- 某项失败继续处理其他项；保留成功项，不自动回滚或删除用户文件。失败项若留下部分文件，明确显示位置，不冒充成功。
- 安装收据只记录实际新装并通过校验的项，保存来源目录后刷新列表。

## 验证
- 多项均安装完整，预览下载仅一次；单项导入回归。
- 子集选择、零选中、非法选择、重复选择、同名冲突。
- 已存在有效技能、无效已有目录、部分失败结果、快照生命周期。
- UI 全选/取消全选、数量按钮、忙碌状态、逐项结果与返回列表。
- 通过测试后打包与启动检查；部署需分别报告完成状态，不能将源代码修改等同于已更新桌面应用。

## 取舍
采用独立目录批量安装：保持原技能结构和独立调用能力。拒绝合并成一个 Skill（会改变入口语义）；暂不引入整包更新/卸载管理（超出本次安装范围）。

## 后续确认：统一入口
用户已确认整套安装后创建本地生成的统一入口，仍使用现有复制指令调用。入口是额外的独立 Skill，不合并成员文件；用相对路径列出成员，检查缺失并按任务读取相关真实说明。只对完整且全部成功/已存在通过检查的合集生成；部分失败不生成。入口使用仓库名加来源短哈希避免不同仓库撞名。已有同名入口仅内容完全一致时复用，否则报告不覆盖。不保证 Agent 实际执行成功。
